# Proyecto en equipo CyberCafé

![Bar Café](/public/banner-bar-cafe.png)

> Vale estaremos creando una página web muy simple sobre un CyberCafé

- Vale cuando hayas echo el Fork espero que estes leyendo esto para empezar ejecuta:

```js
npm install
```

una vez instaladas las dependencias, ya pueden ejecutar el siguiente comando para ver la página web:

```js
npm run dev
```

de momento no hay mucho solo cosas simples hasta que se les asignen sus tareas
