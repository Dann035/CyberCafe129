# ⚠️ IMPORTANTE :

## ⌨️ Comnados:

`npm install` //Instala los paquetes necesarios para la página <br>
`npm run dev` //Ejecuta la página para verla en el navegador <br>
`git switch <nombre de la rama>` //Nos permite cambiar a la rama nombrada<br>
`git switch -c <nombre de la rama>` //Nos permite crear y cambiar a la rama nombrada<br>
`git pull <Repositorio> <nombre de rama>` //Nos permite traernos los datos que estan en el repositorio y rama en concreto nombrados<br>
`git add .` //Nos permite preparar todos los archivos modificados para que sean comiteados<br>
`git commit -m "Aqui un mensaje especifico` //Nos permite realizar el commit de los archivos previamente preparados para dejarlos listos para enviar al repositorio decidamos<br>
`git push <Repositorio> <nombre de rama>` // Nos permite **enviar** los datos que estan comiteados y listos a ser enviados al repositorio y rama en concreto nombrados<br>
`git remote -v` // Nos permite **Ver** los repositorios con los que tenemos una conexion establecida<br>
`git remote add <Apodo que queramos> <Url que apunta hacia un repositorio>` // Nos permite **Agregar** una conexion y establecer el envio y obtencion de datos de ese repositorio<br>
`git remote set-url <Apodo al cual queremos cambiarle la direccion> <URL nueva direccion> ` // Nos permite **Ver** los repositorios con los que tenemos una conexion establecida<br>
`git remote rename <Apodo actual> <Apodo nuevo>` // Nos permite **Renombrar** el apodo de nuestras conexiones por ejemplo el que se llamaba origin ahora le ponemos upstream<br>

## ⌨️Atajos de Teclado<br><br>

`Ctrl + C` Permite **Copiar** el texto selecionado<br>
`Ctrl + V` Permite **Pegar** el texto selecionado<br>
`Ctrl + X` Permite **Cortar** el texto selecionado<br>

`Ctrl + J` Permite abrir y cerrar el panel de la terminal en VSCODE<br>
`Ctrl + B` Permite abrir y cerrar el panel de los archivos en VSCODE<br>
`Ctrl + Alt + B` Permite abrir y cerrar el panel del Chat IA en VSCODE<br>

<strong style="color: yellow">En la terminal :</strong>

`Ctrl + C` Permite **Detener** un proceso que este ejecutandose en la Terminal<br>
`Flecha Arriba` Permite **Recorrer** el historial de comandos hacia atras ejecutados en la Terminal<br>
`Flecha Abajo` Permite **Recorrer** el historial de comandos hacia delante ejecutados en la Terminal<br>
